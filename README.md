PulseScope — Sentiment Intelligence & Comment Analytics Platform
PulseScope is a professional, lightweight, client-side sentiment intelligence and customer feedback workspace. It is designed to analyze real user comments, reviews, or social media text across any platform (such as YouTube, TikTok, restaurant reviews, e-commerce portals, or custom uploads) and classify them instantly as Positive, Negative, or Neutral while accounting for emoji sentiment and confidence metrics.

Key Features
Universal Platform Support: Analyze feedback from any source or paste text directly without being locked into a single brand or portal.

Emoji-Aware Sentiment Analysis: Automatically detects, preserves, and weighs emojis (e.g., 😍, 🔥, 💯 for strong positive vs. 😡, 👎, 😭 for negative) to enhance classification accuracy.

Flexible Input Methods:

Single comment analyzer with live character counting.

Bulk text pasting for multiple comments at once.

File and image upload support (plain text .txt, .csv, and image screenshots like .jpg, .png).

Professional Analytics Workspace:

Real-time KPI strip (Total comments, Positive %, Neutral %, Negative %).

Interactive Chart.js donut chart showing sentiment proportions.

Comment Explorer with search and sentiment filters.

AI Insights & Data Chatbot ("Ask Pulse"):

Automated executive summaries and key findings derived directly from the loaded dataset.

Interactive dataset-grounded AI chatbot capable of answering open-ended questions about the analyzed feedback.

Zero Database Complexity: Runs entirely client-side in the browser using HTML5, Tailwind CSS, and JavaScript. No complex backend or database setup is required.

Light & Dark Mode: Fully intentional dark navy/charcoal editorial theme (#0B0F19) with a built-in light mode toggle.

Tech Stack
Frontend: HTML5, Tailwind CSS (via CDN)

Icons: Lucide Icons

Charts: Chart.js

Logic & NLP Rule Engine: Vanilla JavaScript (VADER lexicon adapted with custom emoji weights)

Getting Started / Local Installation
Because PulseScope is built as a single, self-contained web application, running it locally takes seconds:

Copy the complete source code of the application.

Save the file on your computer as index.html.

Double-click the index.html file to open it instantly in any modern web browser (Chrome, Firefox, Edge, Safari).

Deployment
PulseScope can be deployed instantly for others to access via a public URL without requiring any server configuration or database provisioning:

Vercel: Drag and drop your project folder or repository into Vercel for instant static deployment.

GitHub Pages: Push your index.html to a public GitHub repository and enable GitHub Pages under repository settings.
